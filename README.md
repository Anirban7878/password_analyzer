# 🔐 Password Strength Analyzer

A Python-based tool that analyzes the strength of a password and provides suggestions to make it more secure.

---

## 🚀 Features

- Checks password strength (Weak / Medium / Strong)
- Detects common patterns and weak passwords
- Suggests improvements for stronger security
- Uses Regex for pattern matching

---

## 🛠️ Tech Stack

- Python
- Regex (re module)
